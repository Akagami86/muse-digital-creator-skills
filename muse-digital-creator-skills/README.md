# Muse Digital Creator Skills

Paket skill untuk membangun alur kerja Muse AI Agent khusus pekerjaan digital creator. Sistem ini terpisah dari repository make.fun dan tidak mengubah skill yang sudah ada.

## Struktur peran
- **Dayita** — Orchestrator/Executor: menerima brief, membagi tugas, mengatur alur, dan memastikan hasil akhir terkirim.
- **Hermes** — Research Analyst: meneliti audiens, tren, kompetitor, referensi, dan spesifikasi platform.
- **Strategist** — Creative Director: membuat 3–7 konsep, menilai, lalu mengunci satu arah kreatif.
- **Creative Studio** — Spesialis produksi: desain Canva, gambar AI, identitas brand, produk digital, video, copywriting, dan UI/UX.
- **Supervisor** — Juri independen: memeriksa konsep dan hasil akhir dengan keputusan APPROVED, CONDITIONAL, atau REJECTED.

## Instalasi
1. Unduh dan ekstrak ZIP ini.
2. Unggah folder `digital-creator-system` beserta seluruh isinya ke repository GitHub `muse-digital-creator-skills`.
3. Pastikan setiap folder skill memiliki file `SKILL.md`.
4. Pasang skill dari repository melalui Muse AI Agent / sistem instalasi skill yang tersedia.
5. Uji dengan satu brief sederhana sebelum digunakan untuk proyek penting.

## Alur kerja wajib
Brief → Dayita → Hermes → Strategist → Supervisor (gerbang konsep) → Creative Studio → Supervisor (QC akhir) → Dayita (serah terima).

Supervisor dapat meminta revisi. Hasil berstatus REJECTED tidak boleh diteruskan sebagai hasil final. Jangan mengklaim desain, file, riset, atau publikasi sudah dibuat jika belum benar-benar dilakukan dan diverifikasi.
